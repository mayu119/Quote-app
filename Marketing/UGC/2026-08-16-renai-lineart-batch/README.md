## 装置のA/B設計

- 本命仮説: アプリ項目は**4枚目**(図星2〜3連発の直後、最初の「わかる」のピーク)。1・2本目で検証。
- 対抗: **締めの名言カードに日記行の脚注**を付ける形(3本目)。男性の行動リスト系はアプリを項目として混ぜられないため、この型が必要になる。成績を比較する。
- 共通ルール:
  - 装置スライドは機能説明禁止。実在名言のカード+日記行「今日はこれだった」のみ。アプリアイコンは置かない。
  - アプリを説明しない。「〜ってアプリで」のような紹介口調は禁止。既にみんな使っている前提の書き方(「寝る前はWords for Meで一枚だけ引いてる」)にする(2026-08-16 Mayu指示)。
  - 締めスライドは売らない。「今日の言葉」カード様式+Words For Me透かしのみ(3本目の脚注が唯一の例外)。
  - 名言はすべてquotes.json実データ(love_crush)から使用。製品と投稿の内容一致を守る。
