## 視覚言語

2層に分ける。**画像生成は枠の線画にだけ使い、カード層では使わない。**

| 層 | 使うもの | 値 |
|---|---|---|
| 枠（表紙・導入・解説・**棚**・締め） | 現行 v3-lineart と同一 | 生成りオフホワイト `(246,242,235)` / 墨色 `(63,60,56)` / 罫 `(133,126,116)` / ヒラギノ明朝＋英文セリフ小見出し ＋ **gpt-image-2 で生成した一本線イラスト**（`lineart/`）。顔を描かない・影なし・着色なし。`wfm_render.lineart()` で PAPER/INK の2値に正規化してから敷く |
| カード（名言） | アプリ実物 | `Assets.xcassets/Backgrounds` の実背景写真 ＋ `VerticalTextView.swift` と同じ縦書き（HiraMinProN-W6、句読点 `+0.6em/-0.6em`、小書き仮名 `+0.15em/-0.15em`、`ー「」()` は90°回転）＋ 金の縦罫 `(217,166,51)` ＋ `drawDarkGradient` と同じ `0.3→0.6→0.9` |

カード側の背景は `quotes_full.json` の `background_image` をそのまま使う（`women_original_212` → `purple_moon`）。**カード層では画像生成を使わない。**

## タイトル

**既読のままの画面を、まだスワイプできない人へ**（22字）

- 型: ナラティブ・未完了＋対象指名
- 「スワイプできない」は行動描写（勝ちタイトル銀行の勝ち群 73.3%）であり、かつアプリ側のジェスチャと韻を踏む。**スワイプできない画面 → スワイプする言葉** で1枚目と3枚目が対になる
- 却下した型: **卒業報告型**（「〜をやめた話」）は銀行の却下事例。**問いかけ**は勝ち群 30本中 0本
- 数字と `【】` は不採用。縦書きだと `【午前1時】` が5字の独立列になり右端だけ痩せる（`【】` 43.3% は横書き前提の数字）

### 表紙の改訂（2026-08-21 Mayu判断）

縦書きタイトル＋英文小見出し＋サブコピーの3要素構成をやめ、**横書きタイトル1要素**にした。

| | 旧 | 新 |
|---|---|---|
| 書字方向 | 縦書き | **横書き** |
| 字送り | 61px（`H*0.42` の箱に最長12字を詰めるため痩せる） | **72px**（1.18倍） |
| 併置する文字 | `STILL CANNOT SWIPE AWAY` ＋「通知が来るたび、違う名前だった。」 | **なし** |
| 線画の位置 | 0.69〜0.95H | **0.12〜0.38H** |

線画を上へ送ったのは、下揃えのままだと **TikTokのキャプション／ユーザー名が乗る下25%と机の絵が重なる**ため。型3の勝ち構図（線画=上／タイトル=中下／下は空ける）と同じ配置になる。

同じ理由で 2枚目・4枚目の線画も送った（旧 0.65〜0.88H / 0.76〜0.84H → 下端を 0.72H で止める）。`render.py` の `SAFE_BOTTOM` 一箇所で制御している。

### 5枚目の作り直し（2026-08-21 Mayu指摘）

旧版は実物カードを4枚横に並べていたが、**そんな画面はアプリに無い**。`WeeklyShelfView.swift:20-26` の実画面は `punchline` のテキスト行が縦に積まれたリストで、カードのサムネイル並びは作り物だった（型5の「実画面の合成をしない」に抵触）。

**採ったのは構造だけで、見た目は採らない。** 実画面のUI言語（ダーク地・角ゴ・角丸パネル）でそのまま描くと、この1枚だけ生成りオフホワイト＋明朝のデッキから浮く（2026-08-21 Mayu指摘）。行リストという構造を実画面から採り、色と書体は枠スライドに合わせる。iOS UI版は `shelf_app_ui()` に比較用として残してある。

| | 旧 | 新 |
|---|---|---|
| 構造 | 実物カード4枚を横並び | `WeeklyShelfView` と同じ punchline の行リスト |
| 名言の可読性 | カード幅208pxまで縮み**読めない** | 本文 48px |
| 視覚言語 | 枠（オフホワイト＋明朝） | 枠のまま（区切りは角丸パネルでなく罫） |
| ラベル | 「今週の棚」34px | 見出し「私の棚」＋「今週は「好きな人ができた時」の言葉を3枚集めました。」 |
| 下端 | `WHAT STAYED THIS WEEK` が 0.86H | 0.68H |

棚は3枚に減らした。**`women_original_217` は `relationships`（対人関係）で、「好きな人ができた時」の言葉として数えると実データと食い違う**ため外している。`shelf()` は棚のカテゴリー混在を `assert` で弾く。

行が下の帯へ届く場合は `.title3`(20pt) から一段ずつ字を落として収める。実画面はスクロールできるがスライドはできないため。

削除した3枚（8枚→6枚）:

- `push_notification_hook`「スマホを何度も見てしまう夜に。」— タイトルの「スワイプできない」と訴える行動が重複。
- 棚メモ「「既読つけなきゃよかった」って打って、消して、「1時間待てた」に変えた。」— **Mayu判断で削除**（2026-08-21）。
- 棚スライドの一行「この4枚は、まだ棚にある。」— **Mayu判断でピンとこないため削除**（2026-08-21）。手書きの一行を足さなくても、実画面の説明行がその役を持つ。
