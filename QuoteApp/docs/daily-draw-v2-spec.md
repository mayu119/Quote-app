# 「儀式の一枚」v2 正式仕様

更新日: 2026-07-13  
対象Issue: #5 / #9 / #24

## 1. 決定

起動体験は、毎日最初の1回だけ表示する `DailyDrawView` に一本化する。現在の `DailyRitualView` は意図・手放すもの・行動を選ぶ別機能であり、毎日起動のゲートには使わない。`Config.enableSpiritualRitual` 配下の既存機能は「設定から任意で開く深い儀式」として残し、自動表示は廃止する。

オンボーディングの `PrescriptionRevealView` と `DailyDrawView` は、カードの伏せ面、1.5秒のめくり、ハプティクス、Reduce Motion対応を `CardRevealContainer` として共有する。

## 2. 表示優先順位

1. 初回起動でオンボーディング未完了ならオンボーディング
2. オンボーディング完了済みで当日未表示なら「儀式の一枚」
3. 当日表示済みなら直接スワイプデッキ

通知・ウィジェット・通常アイコンのどこから起動しても同じ判定を使う。ギフトのUniversal Linkだけは受取体験を優先し、閉じたあとに未表示なら儀式へ遷移する。

## 3. 状態と日付境界

`DailyDrawRecord` を端末内に保存する。

| フィールド | 内容 |
| --- | --- |
| `localDayKey` | `Calendar.autoupdatingCurrent` で生成した `yyyy-MM-dd` |
| `presentedAt` | 儀式画面を最前面に出した時刻 |
| `timeZoneID` | 表示時のタイムゾーン |
| `quoteID` | 選ばれた言葉 |
| `state` | `presented` / `revealed` / `saved` / `toDeck` / `skipped` |
| `algorithmVersion` | 選定ロジックの版 |

画面が表示された時点で当日の記録を作る。アプリを途中終了しても同日に再表示しない。直近14日分の `localDayKey` を保持し、タイムゾーン移動で過去の日付に戻っても同じ日付を二重表示しない。現地日付が新しくなれば、前回から24時間未満でも新しい一枚を表示してよい。

## 4. 所作

1. 伏せたカードと「今日のあなたに、一枚。」を表示する。21時以降は「今日を、許して閉じる。」にする。
2. ユーザーのタップまで自動でめくらない。「今日は引かない」でデッキへ進める。
3. タップ後、1.5秒のめくりと軽いハプティクスを行う。Reduce Motion時はクロスフェード0.2秒にする。
4. 言葉を開示し、「棚に置く」「今日はこれだけ」「もう少し読む」を表示する。
5. この画面には価格、Premiumバッジ、ロック、購入・復元導線を置かない。

## 5. 言葉の選定

- 21:00〜04:59は `want_to_quit` を中心にした夜プールから選ぶ。命令形・叱咤の言葉は夜プールに入れない。
- 05:00〜20:59は通常プールから選ぶ。
- 通常は `preferredCategories` から重複回避付きで選ぶ。
- インストールIDと `localDayKey` の安定ハッシュが3で割り切れる日だけ、`affinityScores` 最上位カテゴリの候補を優先する。
- 過去14日以内に儀式で出した `quoteID` は候補から除く。候補不足時だけ期間を7日、3日の順に緩和する。
- 無料・有料で選定品質と儀式体験を変えない。

## 6. 画面遷移

| 操作 | 保存 | 次画面 |
| --- | --- | --- |
| 棚に置く | お気に入りと `favoritedAt` を保存 | 完了表示後にデッキ |
| 今日はこれだけ | なし | アプリの静かな終了画面。戻ればデッキ |
| もう少し読む | なし | デッキ |
| 今日は引かない | なし | デッキ |

「棚に置く」で無料保存上限に達していても、儀式の一枚だけは保存できる。課金判断は次回デッキ内で行い、儀式の途中に割り込ませない。

## 7. 計測契約

| イベント | 必須パラメータ |
| --- | --- |
| `daily_draw_presented` | `time_slot`, `source`, `algorithm_version` |
| `daily_draw_revealed` | `time_slot`, `quote_id`, `is_affinity_hit`, `reveal_ms` |
| `daily_draw_saved` | `quote_id`, `time_slot` |
| `daily_draw_to_deck` | `quote_id`, `entry_action` |
| `daily_draw_skipped` | `time_slot`, `source` |

D7/D30は `daily_draw_revealed` 経験者と、表示されたが `daily_draw_skipped` した利用者で比較する。イベント名は上記を正とし、旧案の `logDailyDraw` 等は実装時にこの名前へ統一する。

## 8. 移行と削除

- `lastDailyRitualPresentedDate` は新しい記録へ移行しない。v2初回だけ新しい一枚を表示する。
- `lastNightWordPresentedDate` による独立した自動夜画面は廃止し、夜の一枚を本機能へ統合する。
- 未接続の `TodayQuoteView` は `CardRevealContainer` に転用できない場合は削除する。
- 既存のデッキ上限、11枚目ロックプレビュー、ペイウォール文脈は変更しない。

## 9. 受け入れテスト

- 23:59に表示後、00:01に翌日の一枚が表示される。
- 同日中の再起動、通知起動、ウィジェット起動では再表示されない。
- タイムゾーンを進めた場合は現地の新しい日付で表示され、戻しても同一 `localDayKey` は再表示されない。
- 20:59は通常、21:00は夜プールになる。
- VoiceOverで伏せ面、開示、3つのCTA、スキップを順に操作できる。
- Reduce Motion、文字サイズAX5、オフラインで完走できる。
- 儀式画面のView階層と遷移先に課金導線がない。
- デッキ側の上限とロックプレビューの既存テストが通る。
